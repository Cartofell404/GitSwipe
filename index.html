Privacy & Legal

1. Personal Data & Analytics

This application does not collect, store, or share any of your personal data. There are no tracking scripts, cookies, or third-party analytics (like Google Analytics) embedded in this website.

2. Local Storage

To make the application work properly, we use your browser's Local Storage to save your preferences (like saved repositories and the community-card choice). This data never leaves your device and you can clear it at any time using the "Clear all" button in the app or via your browser settings.

3. Hosting, Server Logs & GitHub

This website is hosted using GitHub Pages. GitHub may collect server logs, including your IP address, for security and operational purposes. The app also loads repository data, avatars, banners and README images directly from GitHub (api.github.com and GitHub's image servers), so GitHub can see your IP address while you use it. Nothing is loaded from Google or other third parties: the display font is hosted on this site. For more details, please read the GitHub Privacy Statement.

4. Contact & Ownership

This is a non-commercial, open-source hobby project created by cartofell404. If you have any questions or want to report an issue, you can reach out via GitHub.
